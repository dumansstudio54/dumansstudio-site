# DumansStudio — Tanıtım Sitesi (dumansstudio.com)

Sakarya/Adapazarı'ndaki DumansStudio'nun tanıtım sitesi. Reformer Pilates · EMS · Yoga · Eğitmen Merve Duman.

## Yapı

Tüm dosyalar **klasörsüz**, deponun ana dizinindedir (GitHub web yüklemesi klasörleri düzleştirdiği için).
Sayfalar: `index.html`, `reformer-pilates-nedir.html`, `ems-antrenmani-nedir.html`.
Tasarım `site.css`, davranış `site.js`, etkinlik takvimi `takvim.js`. Görseller ve fontlar da ana dizinde.
**Bir dosyayı güncellerken diğerlerini silmeyin.**

## Yeni etkinlik eklemek

`etkinlikler.js` → kalem ikonu → dosyanın başındaki örnek bloğu kopyalayıp doldurun → **Commit changes**.

## Yayınlama

Depo Netlify'a bağlıdır; her commit'ten ~1 dakika sonra site güncellenir.
GitHub web yüklemesi tek seferde en fazla 100 dosya alır.
